# 🎰 Lucky Casino — Telegram Mini App

Пять игр в одном казино: **Слоты · Кости · Монетка · Плинко · Рулетка**.
Одностраничное приложение без зависимостей (vanilla HTML/CSS/JS в одном файле).

**Продакшен:** https://matveitatus-create.github.io/Tz1k/

## Игры и выплаты

| Игра | Правило | Выплаты |
|---|---|---|
| Слоты | 3 в ряд / пара | три 7️⃣ — весь джекпот; три 💎 ×15; любые три ×10; пара ×2 |
| Кости | игрок против дилера | победа ×2, ничья — возврат ставки |
| Монетка | орёл/решка на выбор | угадал ×2 |
| Плинко | 8/12/16 рядов, риск low/med/high | до ×1000 (таблицы симметричны, RTP 97–99%) |
| Рулетка | европейское колесо, ставки по полю | число 35:1, дюжины/колонки/внешние по стандарту |

## Механики

- **Прогрессивный джекпот**: +10% каждой ставки во всех играх; срывается тремя 7️⃣, сбрасывается на 500.
- **Бонус**: +100 монет раз в 12 часов (кнопка 🎁, кулдаун персистится).
- **Персист**: баланс, ставка, серии, истории раундов и джекпот хранятся в `localStorage` (ключ на пользователя TG; фолбэк `guest` вне Telegram).
- **Автоспин слотов**: ⚡ АВТО; автоматически останавливается при сворачивании приложения и при уходе с вкладки слотов.
- **Telegram-интеграция**: `WebApp.ready()/expand()`, haptic-отклик, имя пользователя через `textContent` (без инъекций).

## Доступность и надёжность

- aria-live на результатах всех пяти игр; `lang="ru"`; клавиатурные вкладки (role=tab, Enter/Space); aria-label на кнопках без текста.
- Tap-targets ≥44 px и шрифты ≥10 px во всех панелях; поддержка `prefers-reduced-motion`.
- Защита записи/чтения `localStorage` (приватный режим iOS WebView, квота); клампы ставки `[10, баланс]`.
- OG-мета 1200×630, preconnect шрифтов, только используемые веса шрифтов.

## Структура и деплой

- `index.html` — всё приложение (разметка, стили, логика).
- `og.png`, `favicon.svg` — превью и иконка.
- Деплой: push в `main` → GitHub Pages (каталог-репозиторий `Tz1k-deploy` зеркалит `index.html`).
